# Security Policy

## Intended use

NetHound is intended for lawful OSINT, defensive monitoring, and authorized security research. Newly registered domains are not inherently malicious; users should validate findings with independent signals and context.

Only investigate domains and infrastructure within the scope of your authorization and applicable law.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details, credentials, tokens, or private information in a public issue.

Use GitHub's private vulnerability reporting flow for this repository, when available:

1. Open the repository's **Security** tab.
2. Choose **Advisories**.
3. Select **Report a vulnerability** and provide the details privately.

If private reporting is unavailable, contact the maintainer through the GitHub profile and ask for a private disclosure channel before sending sensitive details.

When reporting, include the affected version or commit, impact, reproduction steps, and any safe proof of concept. Please allow the maintainer time to investigate and prepare a fix before public disclosure.
